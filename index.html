How does a GPU run thousands of threads at once?

This tool shows you the pieces, a thread, a warp, a block, and the grid, and how they fit together. No CUDA experience needed. If you're brand new, take the guided tour. It uses a simple army analogy and walks you through everything in a couple of minutes.

Glossary

Thread — the smallest unit of work. One thread runs your kernel code once. A real CUDA launch has thousands of them. Analogy: one soldier.

Warp — a group of exactly 32 threads. The warp is the unit the hardware actually executes. All 32 threads in a warp run the same instruction at the same time (SIMT). Analogy: a squad of 32 who must move in lockstep.

Lane — a thread's position inside its warp, numbered 0 to 31. lane = tid % 32.

Block — a group of threads that can cooperate and share fast on-chip memory. A block can have up to 1024 threads, organised in 1D, 2D, or 3D. Analogy: a platoon.

Grid — the full set of blocks launched together. Blocks run independently and can be scheduled in any order. Analogy: the whole army.

SIMT — Single Instruction, Multiple Threads. All 32 lanes in a warp issue the same instruction at the same instant. When code branches, lanes take different paths sequentially (see Warp Divergence).

Warp Divergence — when threads in the same warp need to do different things (an if-statement), the warp splits and runs each path one after another. The warp is only as fast as the slowest path.

Memory Coalescing — when all 32 threads of a warp read data from the same small chunk of memory (a 128-byte segment), the GPU fetches it in one transaction. When the data is scattered across many chunks, it needs many transactions, and most of each is wasted.

SM — Streaming Multiprocessor. One of the GPU's processing cores. A modern GPU has tens to hundreds of SMs. The runtime schedules blocks onto SMs.

Occupancy — the ratio of active warps on an SM to the maximum the SM supports. Higher occupancy helps the GPU hide memory latency by switching between warps.

Kernel — a function that runs on the GPU, written in CUDA C++ and launched from host code with the <<<grid, block>>> syntax.
